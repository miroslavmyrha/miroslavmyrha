# Miroslav Myrha

I build web applications and the tests that keep them working. Ten years in IT.

**What I work with:** Vue, Nuxt, TypeScript, Django, PostgreSQL · Playwright, Cypress, CI/CD · Claude Code, MCP servers and local models as coding agents.

## Open source

- [cypress-mcp](https://github.com/miroslavmyrha/cypress-mcp) – MCP server that lets an AI assistant read Cypress specs and the results of the last test run
- [po-generator](https://github.com/miroslavmyrha/po-generator) – CLI that crawls a web app and generates Playwright Page Objects and tests with an LLM
- [harness](https://github.com/miroslavmyrha/harness) – minimal harness for running local open-weight models as coding agents, with validation outside the model
- [gov-design-demo-simple](https://github.com/miroslavmyrha/gov-design-demo-simple) – the Czech Gov Design System with Nuxt 4, hydration done right
- [cypress-testrail-turbo-reporter](https://github.com/miroslavmyrha/cypress-testrail-turbo-reporter) – Cypress results reported to TestRail
